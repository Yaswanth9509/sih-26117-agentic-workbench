01 - The reason

AI is easyto ask.AI is harderto trust.

The system does not ask one model to do everything. It gives every stage a boundary.

The workbench separates understanding, retrieval, reasoning, validation and decision-making so an answer can be inspected instead of simply accepted.

05 - When things go wrong

Failure is aroute, notan outage.

The reasoning layer can use a local model, optional cloud providers, or a rule-based floor. Provider failures degrade safely; repeated failures open a circuit, then recover through a half-open retry.
